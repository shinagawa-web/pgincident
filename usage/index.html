Usage#

Once .pgincident.toml is in place, run:

pgincident

The tool reads the config, connects to the database, and opens the TUI. You start on the Overview screen.

Screens#

ScreenPurpose
OverviewGlobal health at a glance — spot what’s wrong
DashboardPer-category incident view — long-running queries, locks, idle in transaction
Query detail overlayFull SQL for a selected query with scrolling
